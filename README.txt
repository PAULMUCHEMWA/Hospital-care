CAREDESK - HOSPITAL RECORDS APP

DEPLOY (GitHub then Netlify)
1. Unzip this file. You get 5 files: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png.
2. Create a NEW GitHub repository (for example: caredesk). Do not use First-Project, it holds the Purematrix map.
3. Upload the 5 files to the new repo (Add file > Upload files) and Commit.
4. Netlify > Add new project > Import an existing project > GitHub > caredesk. Leave build settings empty. Deploy.
5. Open the link in Chrome > menu > Install app.

STARTER PINS (change them in index.html, search for "ROLES")
Reception 1111, Doctor 2222, Pharmacy & Finance 3333, Administrator 0000

REAL PHOTOS (optional)
Upload a photo named images/doctors.jpg to the repo and it appears in the banners automatically.

IMPORTANT
Records are saved only in the browser of each device. Do not enter real patient data until a secure shared database and proper logins are added.
